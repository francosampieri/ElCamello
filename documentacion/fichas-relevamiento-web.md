# Parador El Camello — Información para desarrollar la web

Documento de trabajo para completar entre la familia, el responsable comercial y el desarrollador.

El objetivo es reunir la información necesaria para presentar el lugar, explicar sus propuestas y facilitar consultas por WhatsApp. Pueden responder con frases breves, audios, documentos existentes o referencias a carpetas del Drive. Nosotros organizaremos esa información y redactaremos los textos de la web para su revisión.

No hace falta completar todo de una vez. Si algo no está decidido, escribir **“pendiente”**. Una posibilidad en evaluación debe distinguirse de un servicio que ya se puede contratar.

## Cuándo necesitamos cada cosa

| Etapa | Qué necesitamos | Para qué |
|---|---|---|
| **1. Para empezar** | Definición general del lugar, propuestas que queremos mostrar, servicios principales, referencias visuales y una persona que apruebe. | Definir secciones, páginas y diseño inicial. |
| **2. Durante el desarrollo** | Fotos seleccionadas, detalle de propuestas y opcionales, historia, preguntas frecuentes y accesos técnicos cuando correspondan. | Completar los contenidos y ajustar el diseño. |
| **3. Antes de publicar** | Datos comerciales definitivos, límites que se comunicarán, contacto, ubicación y aprobación de textos e imágenes. | Publicar información confirmada y probar las consultas. |

Los números exactos de capacidad, mínimos de personas y horarios pueden completarse al final si solo implican ajustar textos. Para empezar sí necesitamos saber si una propuesta depende de condiciones que cambian lo que vamos a mostrar: por ejemplo, si hay pernocte, uso exclusivo del predio o actividades disponibles solo en cierta temporada.
